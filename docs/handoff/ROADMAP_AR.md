# خارطة الطريق

## الإصدار 0 — الهيكل الآمن
- تشغيل الخدمة والتحقق من المسارات.
- لا جرد شامل ولا تعديل للمصدر.

## الإصدار 1 — الجرد القابل للاستئناف
- تعداد المجلدات تدريجيًا.
- تخزين المسارات النسبية وحجم الملف وتاريخ التعديل.
- معالجة أخطاء الوصول لكل ملف دون إيقاف المهمة.
- متابعة تقدم المهمة وإعادة المحاولة.

## الإصدار 2 — استخراج المحتوى
- إضافة قارئ واختبارات لكل امتداد على حدة.
- استخراج مع المحافظة على النص الأصلي والترتيب والإجابات.
- تخزين نسخة المحتوى المستخرج مع مرجع الملف ومؤشر التغيّر.

## الإصدار 3 — الأطر والمطابقة
- استيراد الأطر المعتمدة وإصداراتها.
- منع إعادة تسمية المؤشرات أو إنشاء مؤشرات غير موجودة.
- حفظ نتيجة المطابقة وسببها ودرجة الثقة وحالة المراجعة.

## الإصدار 4 — جودة وتصدير
- كشف التكرار الحرفي وشبه التكرار والتداخل المفاهيمي.
- تصدير Excel وGIFT مع اختبارات آلية.
- اعتماد المراجعة البشرية قبل التصدير النهائي.

## شروط الانتقال إلى المعالجة الكاملة
- اختبار الاستعادة بعد توقف الخدمة.
- اختبار صلاحيات القراءة فقط للمصدر.
- اختبار عينات عربية وإنجليزية وصيغ متعددة.
- قياس الأداء الفعلي وتحديد حجم الدفعة المناسب.
- موافقة تقنية المعلومات ومسؤول بنك الأسئلة.
