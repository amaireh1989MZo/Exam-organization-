# التكرار، وفك ZIP الآمن، وتقرير Excel

> **الحالة:** منفّذ ومختبَر على بيانات اصطناعية. لا يحتاج أي عينات.

---

## 1. كشف التكرار

### التطبيع (للمقارنة فقط، النص المحفوظ لا يتغير)
| ما يُوحَّد | مثال |
|---|---|
| التشكيل والتطويل | `عاصمةُ` = `عاصمة`، و`مدرسـة` = `مدرسة` |
| صور الألف | `أ إ آ ٱ` ← `ا` |
| الياء والتاء المربوطة والهمزة على الواو والياء | `ى` ← `ي`، و`ة` ← `ه`، و`ؤ` ← `و`، و`ئ` ← `ي` |
| الأرقام العربية والفارسية | `١٢` ← `12` |
| علامات الترقيم والرموز والمسافات المتعددة | تُحذف أو تُختصر إلى مسافة واحدة |
| حالة الأحرف اللاتينية | أحرف صغيرة |

### الفئات
| الفئة | المعنى | لماذا تهم |
|---|---|---|
| **تكرار حرفي** | النص ومجموعة الخيارات متطابقة بعد التطبيع، **بغض النظر عن ترتيب الخيارات** | نسخ السؤال نفسه في ملفات وسنوات مختلفة |
| **النص نفسه بخيارات مختلفة** | النص متطابق والخيارات مختلفة | نسخة معدّلة، أو سؤال مختلف بالصياغة نفسها |
| **الإجابات مختلفة بين النسخ** (علامة حمراء) | نسخ متطابقة لكن **نص** الإجابة الصحيحة مختلف، والمقارنة بالنص لا بالموقع | أخطر حالة: إحدى النسخ خاطئة حتمًا |

- **لا يُحذف ولا يُعدَّل أي سؤال.** المجموعات تُعرض جنبًا إلى جنب، والقرار للجنة.
- **الأسئلة المُستبدَلة** (بعد تغيّر ملفها) مستبعدة.
- **البصمات تُحسب عند الاستخراج.** الأسئلة المستخرجة قبل إضافة الميزة تُحسب بصماتها تلقائيًا عند تشغيل التطبيق.

### لم يُنجز بعد
- **شبه التكرار** (صياغة مختلفة قليلًا) و**التداخل المفاهيمي**. يحتاجان MinHash ونموذج التضمين المحلي، وسيُبنيان مع مرحلة التصنيف.

## 2. فك ZIP الآمن

| الحماية | القيمة الافتراضية | الإعداد |
|---|---|---|
| حجم ملف ZIP نفسه | 50 ميغابايت | `QuestionBank:Uploads:MaxFileSizeMb` |
| عدد الملفات داخله | 2000 | `MaxZipEntries` |
| الحجم الكلي بعد الفك | 1024 ميغابايت | `MaxZipTotalMb` |
| نسبة الضغط لكل ملف (حماية من «قنبلة ZIP») | 100 | `MaxCompressionRatio` |
| ZIP داخل ZIP | مرفوض | — |
| قبول ZIP أصلًا | مفعّل | `AllowZip` |

- **الأحجام المعلنة داخل ZIP قد تكون مزيفة.** لذلك القراءة الفعلية لكل ملف محدودة بحجمه المعلن + 1 بايت، وبالمتبقي من الحد الكلي. التجاوز يُرفض.
- **أسماء الملفات داخل ZIP لا تُستخدم كمسارات أبدًا.** كل ملف يُحفظ باسم بصمته مثل أي رفع عادي. المسار داخل ZIP يُحفظ للعرض فقط، مثل `حزمة.zip/2023/أسئلة.txt`. اختبار خاص بأسماء مثل `../../../x` يثبت ذلك.
- **ما يُتجاهل يُعرض مع السبب:** صيغة غير مقبولة، أو ضغط مشبوه، أو ZIP داخلي.
- **في الواجهة:** بطاقة لملف ZIP بالملخص، ثم بطاقة لكل ملف استُخرج منه.

## 3. تقرير Excel

زر **«تقرير Excel»** في لوحة الحالة. التقرير يُنشأ ويُنزَّل، وتُحفظ نسخة منه في `OutputRoot/reports/`.

| الورقة | المحتوى |
|---|---|
| **ملخص** | التاريخ، ومن أنشأه، والملفات حسب الحالة، والمفقود، والمرفوع، والأسئلة حسب حالة المراجعة، وعدد عمليات التصدير |
| **الملفات** | كل ملف مسجّل: المسار، والامتداد، والحجم، والتاريخ، والحالة، والخطأ، والبصمة، وعدد الأسئلة |
| **الأسئلة** | كل سؤال: المعرّف الثابت، والمصدر، والموقع، والنص، والخيارات، وإجابة الملف، والتصحيح، والإجابة الفعّالة ونصها، وطريقة الكشف، والثقة، والحالة، والملاحظات، ومن راجعه |
| **التكرار الحرفي** | كل مجموعة ونسخها ومصادرها |
| **الأخطاء** | الملفات الفاشلة، والمرفوعات الفاشلة، والمجلدات التي تعذّر جردها |

**قرارات التقرير:**
- **كتابة متدفقة:** الصفوف تُكتب من قاعدة البيانات إلى الملف واحدًا بعد آخر، فلا يُحمَّل كل شيء في الذاكرة. مناسب لمئات آلاف الأسئلة.
- **كل نص يُكتب كنص وليس كصيغة.** سؤال يبدأ بـ `=SUM(...)` يظهر كما هو ولا يُنفَّذ (حماية من حقن الصيغ). اختبار يتحقق من عدم وجود أي صيغة في الملف.
- **الأوراق من اليمين لليسار**، والصف الأول مثبت، والعناوين بخط عريض.
- **محارف التحكم تُحذف،** والنص الأطول من حد Excel للخلية (32,767 حرفًا) يُقص بعلامة «(مقصوص)».
- **التنزيل:** يقبل فقط أسماء الملفات التي ينشئها التطبيق نفسه، ويتحقق أنها داخل مجلد التقارير.
- **التقرير يحتوي نصوص الأسئلة،** لذلك هو لمدير النظام ومسؤول البنك فقط، ويُسجَّل إنشاؤه في سجل التدقيق.

## 4. الاختبارات

**168 اختبارًا، جميعها ناجحة**، منها 28 جديدة:
- **التطبيع:** 5 حالات.
- **التكرار:** بين ملفات مع تشكيل وترتيب خيارات مختلف، والإجابات المختلفة، والإجابة نفسها في موقع مختلف، والنص نفسه بخيارات مختلفة، وعدم تغيير أي سؤال، وحساب البصمات للأسئلة القديمة.
- **ZIP:** الاستخراج والتجاهل، وأسماء التسلل، وقنبلة ZIP، والعدد والحجم الكلي، والملف التالف، والقراءة المحدودة.
- **Excel:** الأوراق الخمس، وعدم تنفيذ الصيغ، وRTL، والتدقيق، والأسماء المرفوضة، ومحارف التحكم، والنص الطويل.
- **الأمن:** الصلاحيات وحماية CSRF للنقاط الجديدة.

**مشكلة اكتشفتها التجربة في المتصفح وأصلحتها:** إذا أُفلت ملف قبل وصول إعدادات الرفع من الخادم، كانت الواجهة ترفضه خطأً بأن «صيغته غير مقبولة». الآن تنتظر الإعدادات أولًا.

**تجربة فعلية في المتصفح:**
- رفع ZIP فيه ملف أسئلة وملف `.exe`: استُخرج ملف الأسئلة، وتُجوهل `.exe` مع ذكر السبب.
- شاشة التكرار كشفت أن سؤال ZIP مكرر لسؤال من مجلد الشبكة **بإجابة مختلفة** (إربد مقابل عمّان)، وعلّمته بالأحمر.
- تقرير Excel أُنشئ ونُزّل.
